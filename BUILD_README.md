# TUMBLE RUMBLE: Cosmic Circus
## Installation & Launch Guide

Welcome to **Tumble Rumble**, an original ragdoll physics brawler set in a cosmic circus arena! This guide will help you get started.

---

## Quick Start

### Windows
1. **Double-click** `LaunchGame.bat` to start the game
2. Or navigate to `Builds/Windows/` and run `Tumble Rumble.exe`

### macOS
1. **Double-click** `LaunchGame.sh` to start the game
2. Or navigate to `Builds/macOS/` and open `Tumble Rumble.app`
3. If you see a security warning, right-click the app and select "Open"

### Linux
1. **Run** `./LaunchGame.sh` in terminal
2. Or navigate to `Builds/Linux/` and run `./Tumble Rumble.x86_64`
3. Make sure the file is executable: `chmod +x "Tumble Rumble.x86_64"`

## How to Play

### Objective
Knock out your opponents and be the last one standing! Win rounds to claim victory in the cosmic circus!

### Controls

#### Keyboard & Mouse
- **WASD** - Move your character
- **Space** - Jump
- **E** - Grab opponents or objects
- **Left Mouse Button** - Punch
- **Q** - Use special ability
- **Ctrl** - Crouch
- **Esc** - Pause/Menu

#### Gamepad
- **Left Stick** - Move your character
- **A Button** - Jump
- **X Button** - Grab
- **B Button** - Punch
- **Y Button** - Use special ability
- **Left Bumper** - Crouch

### Game Modes

#### Quick Match
- 2-8 players (human or AI)
- Best of 5 rounds
- Various cosmic arenas

### Win Conditions
- **Elimination** - Knock opponents off the platform into the void
- **Survival** - Be the last player standing when time runs out
- **Points** - Score the most points through various knockout types

### Special Abilities
Each character can use cosmic energy for special moves:
- **Energy Burst** - Push nearby opponents away
- **Speed Boost** - Temporarily move faster
- **Shield Bubble** - Protect yourself from attacks
- And more!

## Arenas

1. **Gravity Well** - Circular platform with gravitational pull
2. **Crystal Cavern** - Slippery crystal floors
3. **Nebula Nexus** - Multiple floating platforms
4. **Meteor Shower** - Avoid falling space rocks
5. **Black Hole** - Get pulled toward the center
6. **Plasma Fountains** - Geysers that launch players
7. **Magnetic Rings** - Shifting magnetic forces
8. **Time Dilation** - Zones with altered time flow

---

## Tips & Strategies

1. **Stay Central** - Avoid the edges to prevent falling into the void
2. **Use Grabs** - Grab opponents and throw them off the platform
3. **Time Your Jumps** - Jump to dodge attacks or recover from knockback
4. **Master Abilities** - Each special ability can turn the tide of battle
5. **Watch Your Footing** - Different arenas have different hazards

## Troubleshooting

### Game won't start
- Make sure all files are extracted to the same folder
- Check that your system meets minimum requirements
- Try running as administrator (Windows)

### Low performance
- Lower the resolution in game settings
- Close other applications
- Update your graphics drivers

### Controller not working
- Plug in controller before starting the game
- Check controller is recognized by your operating system
- Try restarting the game

### No sound
- Check system volume settings
- Verify audio output device is selected
- Try restarting the game
